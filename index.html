MAP Video Lab rclone (SSD)

Personal Google Drive transfer tools for VideoLab.

This application supports the account owner's local video workflow: retrieving authorized project files, organizing reusable external video footage in a shared library, and reading or updating its Google Sheets asset index. It is a personal desktop workflow, not a public file-sharing or stock-media service.

Google access

The read-only project transfer workflow requests Drive read access. The separately authorized shared-footage workflow requests Drive read/write access for library files and the associated spreadsheet. The Google Drive permission can cover the entire account; configured folder restrictions in local tools are application safeguards, not a Google folder-scoped permission.

Files and library metadata remain in the account owner's Google Drive and controlled local storage. This informational website does not accept Google sign-in, receive OAuth tokens, or provide access to the private library.
